# PitchCraft — AI Email Outreach & Pitch Assistant

This workspace contains the complete **PitchCraft** ecosystem:

1. **[`pitchcraft-extension/`](./pitchcraft-extension)**: Production-ready **Google Chrome Extension (Manifest V3)**.
   - 1-click scraper for LinkedIn job postings and candidate profiles
   - 1-click auto-insertion directly into Gmail compose windows
   - Chrome Side Panel & Popup interfaces
   - Multi-tone (Confident, Friendly, Professional, Formal) and multi-length pitch generator
   - Ready to load in Chrome via `chrome://extensions` -> *Load unpacked*.
   - See [Extension README](./pitchcraft-extension/README.md) for full installation guide.

2. **[`pichcraft/`](./pichcraft)**: The Next.js 16 + React 19 web application dashboard for email campaign tracking, contacts CRM, analytics, and templates.
